# Guess Number Game 🎮

A simple and fun console-based guessing game built with **C#**.

## 📝 Description
In this game, the computer selects a random number between **0 and 10**, and the player has **3 attempts (hearts)** to guess it correctly. The program provides hints whether the target number is higher or lower than the user's input.

## 🚀 Features
- Random number generation using the `Random` class.
- Limited attempts (3 lives).
- Real-time feedback (Bigger/Smaller hints).
- Built with C# Console Application.

## 🛠️ How to Run
1. Clone this repository or download the `Program.cs` file.
2. Open it in **Visual Studio** or any C# compiler.
3. Run the program and start guessing!
